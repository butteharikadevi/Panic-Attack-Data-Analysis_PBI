📊 Panic Attack Data Analysis – Power BI Dashboard
A Power BI dashboard designed to analyze panic attack frequency, triggers, severity, and demographic patterns.
The goal is to help identify behavioral trends, high‑risk periods, and potential correlations that can support mental‑health research and early‑intervention strategies.

🎯 Key Objectives
* Understand how often panic attacks occur and when they are most likely to happen
* Identify common triggers and contributing factors
* Analyze demographic patterns such as age, gender, and lifestyle indicators
* Provide a visual, data‑driven summary to support awareness and decision‑making

🔄 Extracting Data from Snowflake
This project supports loading data directly from Snowflake into Power BI.

📌 Dashboard Features

1. Overview Page
* Total panic attacks
* Unique individuals
* Average attacks per person
* High‑level summary KPIs

2. Panic Attack Frequency
Daily, weekly, and monthly trends

Peak hours and high‑risk time windows

3. Trigger Analysis
* Most common triggers
* Trigger frequency distribution
* Trigger combinations and co‑occurrence

4. Demographic Insights
Age‑wise distribution
Gender‑based patterns
Lifestyle or health‑related correlations (if available in dataset)

5. Severity & Symptoms
Severity level breakdown
Common symptoms reported
Symptom‑trigger relationships

🛠️ Tech Stack
* Power BI Desktop
* Power Query
* DAX
* Power BI Template (.pbit)

🚀 How to Use
* Open in Power BI Desktop
* Load your dataset
* Explore the interactive dashboard

📈 Insights You Can Derive
* When panic attacks are most likely to occur
* Which triggers are most common
* Which demographic groups are more affected
* How severity varies across individuals
* Patterns that may help in prevention or early detection
